# ok buddy 💘 <br/><sup><sub><sup>_okcupid's little helpers_</sup></sub></sup>


### overview

a browser extension to streamline the user-experience on okcupid.

### actions

<dl>
    <dt>scan (<kbd>META + numpad 8</kbd>)</dt>
    <dd>scans the text of the current user profile according to set rules, highlights rule matches on the page, and shows a badge with the verdict (✅/❌/❔)</dd>
    <dt>like (<kbd>META + numpad 6</kbd>)</dt>
    <dd>clicks 'like' on the current user profile, and then performs a review on the next one.</dd>
    <dt>pass (<kbd>META + numpad 4</kbd>)</dt>
    <dd>clicks 'pass' on the current user profile, and then performs a review on the next one.</dd>
    <dt>view (<kbd>META + numpad 5</kbd>)</dt>
    <dd>scrolls the page to view the first match of a highlighted term, resulted from a 'pass' or 'like' on a user profile.</dd>
    <dt>message (<kbd>META + numpad 0</kbd>)</dt>
    <dd>clicks 'message' on the current user profile (only available in profile pages, not in 'discovery' page).</dd>
    <dt>skip (<kbd>META + numpad 2</kbd>)</dt>
    <dd>refreshes the page to hopefully load a different user profile.</dd>
</dl>


### settings

<dl>
    <dt>rules</dt>
    <dd>in each textarea, enter the phrases from user profiles you want to highlight (one phrase per line).</dd>
</dl>
